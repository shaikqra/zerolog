## Registry searches — do these yourself, ~3 minutes each

The registries detect and block automated queries, and the UK IPO says in so
many words that its security check exists to stop data mining. So these need a
person. You, specifically, since the result feeds your purchase decision.

**What you are looking for in every search below:** an existing or pending mark
that is identical or confusingly similar to the candidate, in **class 9**
(software) or **class 42** (software services). A dead/expired mark is not a
blocker. A live identical mark in class 9 is.

### UK (most important — it is where you will incorporate)

1. Go to **https://trademarks.ipo.gov.uk/ipo-tmtext**
2. Pass the security check if shown
3. In the search box type **Tallyband** — leave everything else as-is
4. Note any result whose status is "Registered" or "Application under
   examination" and whose classes include 9 or 42
5. Repeat for **Roughtally**, then **Tally** alone (to see the crowd around
   the word), then **Zerolog**

### EU (covers all member states at once)

1. Go to **https://www.tmdn.org/tmview/**
2. Type **Tallyband** in the big search box, press Enter
3. In the left filter, tick Nice class **9** and **42**
4. Repeat for the others

### US (biggest market)

1. Go to **https://tmsearch.uspto.gov/search/search-information**
2. Choose the basic wordmark search
3. Search **Tallyband**, then **Roughtally**, then **Zerolog**
4. Ignore DEAD marks; note LIVE ones in class 9/42

you.** If all three registries come back empty for Tallyband, the name is as
clear as a non-lawyer can establish, and the domain purchase on the 10th is
safe on the trademark axis.
