# ZeroLog phone app, installable

Built from commit af5de78 (Release, unsigned, arm64 device).

Download: [ZeroLog-unsigned.ipa](https://github.com/shaikqra/zerolog/raw/ipa/ZeroLog-unsigned.ipa)

Install it with Sideloadly or AltStore on Windows using a FREE Apple ID.
The tool signs it on your PC; the file here is deliberately unsigned.

Limits of a free Apple ID: the app stops opening after 7 days and must
be reinstalled, and you can have 3 sideloaded apps at once.

This is the PHONE app only. The Apple Watch app cannot be sideloaded —
watchOS apps need a paid Apple Developer account, so rep counting
cannot be tested this way.
